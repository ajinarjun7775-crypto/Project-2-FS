What is variables ?

In JavaScript, a variable is a named container used to store data values that your program can use, reference, and modify later. Think of a variable like a labeled box: the label is the variable name, and what's inside is the value

What is Declaration?

In JavaScript, a declaration is the process of registering a name (identifier) within a specific scope so that it can be used later in your code. You can think of it as "binding identifiers to values" or creating a container to hold data

What is Intialization?

In JavaScript, initialization is the process of assigning an initial value to a variable or object at the time of its creation

3 Types of Keywords ?

Three ways to declare variables: var, let, const

What is compiler in JS and its name ?

In JavaScript, a compiler is a specialized program within the JavaScript engine that translates human-readable source code into high-performance machine code or bytecode that a computer's CPU can execute
