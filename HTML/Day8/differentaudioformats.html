Multi-Format Audio Player

Demonstration of <audio> element with multiple <source> tags

Audio with Multiple Formats

This audio player uses multiple <source> tags to provide fallback support for different audio formats (MP3, OGG, WAV). The browser will automatically choose the first supported format.

Supported Formats in Order of Preference:

  1. MP3 (audio/mpeg) — Best compatibility across all browsers
  2. OGG (audio/ogg) — Excellent open-source alternative
  3. WAV (audio/wav) — Uncompressed, highest quality

How Multiple Sources Work

The browser checks each <source> tag in order and plays the first one it supports. This ensures maximum compatibility across different devices and browsers.

<audio controls>
    <source src="file.mp3" type="audio/mpeg">
    <source src="file.ogg" type="audio/ogg">
    <source src="file.wav" type="audio/wav">
    Your browser does not support the audio element.
</audio>
