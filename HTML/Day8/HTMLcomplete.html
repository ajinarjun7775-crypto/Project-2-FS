HTML Meta Tags

Meta tags are used to provide metadata about the HTML document. They are placed within the <head> section of the HTML code and are not displayed on the webpage itself. Meta tags can include information such as the character set, viewport settings, description, keywords, and author of the webpage.

Types of Meta Tags

  • Charset: Specifies the character encoding for the HTML document.
  • Viewport: Controls the layout on mobile browsers.
  • Description: Provides a brief summary of the webpage's content.
  • Keywords: Lists relevant keywords for search engines.
  • Author: Specifies the name of the author of the webpage.
