What is Semantic HTML?

Semantic HTML uses meaningful tags that clearly describe the purpose of the content, not just how it looks. This improves accessibility, SEO, and code readability.

Common HTML Attributes Explained

Attribute Purpose Example
lang Specifies the language of the content <html lang="en">
id Unique identifier for an element <section id="intro">
class Groups elements (used with CSS) <div class="card">
title Provides extra information (tooltip) <abbr title="HyperText Markup Language">HTML</abbr>
href Defines link destination <a href="https://example.com">Link</a>
src & alt Image source and alternative text <img src="photo.jpg" alt="Description">

Important Semantic Tags

<header> and <footer>

Used for introductory and closing content of a page or section.

<nav>

Contains major navigation links.

<main>

Represents the dominant content of the page. Only one <main> per document.

<section>

Groups related content thematically.

<article>

Independent, self-contained content (blog post, news, etc.).

<aside>

Content that is tangentially related (sidebar, glossary, etc.).

<figure> and <figcaption>

Used for images, diagrams, or code examples with captions.

Quick Tips

  • Always use <html lang="en">
  • Use <main> only once
  • Prefer semantic tags over <div>
  • Always add alt text for images
