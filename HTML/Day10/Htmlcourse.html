Introduction to HTML

HTML (HyperText Markup Language) is the standard markup language for creating web pages. It provides the structure of a webpage and is used to define elements such as headings, paragraphs, links, images, and more. HTML uses tags to mark up content, allowing browsers to display it correctly. It is the foundation of web development and is essential for building websites and web applications.


  • A programming language A language used to structure content on the web A language for styling web pages A language for creating databases

    • HTML is called a markup language because its primary job is to mark up plain text with tags that describe the structure and semantics of content, rather than to perform computations or logic.

    TAGS

    Tags are the building blocks of HTML. They are used to create elements that define the structure and content of a webpage. Tags are enclosed in angle brackets, such as <tagname>, and often come in pairs with an opening tag and a closing tag (e.g., <tagname>...</tagname>). Some tags are self-closing (e.g., <img />).

    Tags can have attributes that provide additional information about the element, such as <img src="image.jpg" alt="Description" />. Tags are used to structure content, create links, embed media, and more, making them essential for web development.

    Elements

    • Root element <html> The root element is an Top most element in an HTML document,It represents the entire document.
    • Container element, These elements act as containers that hold other elements and define the document structure
    • Semantic Container Elements (HTML5)

    Document Container Elements

    Usage: Only once per document

    Element Purpose Where to use
    <head> Contains metadata about the document Use to define the document's title, character set, styles, and scripts
    <body> Contains the visible content of the document Use to define the main content of the webpage

    Semantic Container Elements

    Usage:These are meaningful containers that clearly describe the purpose of their content

    Element Meaning Typical use
    <header> Header for page or section Logo, navigation, or other introductory content
    <nav> Navigation links for the page or section Menu, links, or other navigation content
    <main> Main content of the document Primary content that is unique to the page
    <article> Self-contained content Blog post, news article, or other independent content
    <section> Thematic grouping of content Grouping related content within an article or page
    <aside> Content related to the main content but separate Sidebar, pull quote, or other tangential content
    <footer> Footer for page or section Copyright, contact info, or other footer content


    Element Purpose Typical use
    <div> Generic Block Level Container When no semantic tags fits
    <span> Generic Inline Container Styling Small Part of text
