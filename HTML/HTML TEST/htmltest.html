HTML Fundamentals

Questions and Professional Answers

1. What is HTML and why is it called a markup language?

HTML (HyperText Markup Language) is the standard markup language used to create and structure web pages and web applications. It consists of a series of elements that tell the browser how to display content such as text, images, links, and multimedia.

It is called a markup language because it uses tags to “mark up” or annotate plain text, providing instructions on structure and presentation without being a programming language that performs logic or calculations.

2. What is the difference between HTML and HTML5?

HTML refers to the original and evolving specification. HTML5 is the fifth and latest major revision of the HTML standard, released in 2014 and now the living standard maintained by WHATWG.

Key improvements in HTML5 include:

  • Semantic elements (<header>, <article>, <footer>, etc.)
  • Native support for audio and video
  • Canvas API for graphics
  • Local storage and offline capabilities
  • Form enhancements and validation
  • Removal of obsolete elements (e.g., <font>, <center>)

3. What is the purpose of <!DOCTYPE html> in HTML?

The <!DOCTYPE html> declaration is placed at the very beginning of an HTML document. It informs the web browser about the document type and version, ensuring the browser renders the page in standards mode (strict compliance with modern HTML specifications) rather than quirks mode.

Without it, browsers may render the page inconsistently across different environments.

4. What is the difference between tags and elements in HTML?

Tags are the markup components enclosed in angle brackets, e.g., <p> or </p>.

An element consists of an opening tag, its content (if any), and a closing tag. For example:

<p>This is a paragraph.</p> — the entire construct is an element.

Tags are the syntax; elements are the complete structural units they define.

5. What are semantic tags? Give examples.

Semantic tags are HTML elements that clearly describe their meaning and purpose to both the browser and developers, improving accessibility, SEO, and code readability.

Examples:

  • <header> — introductory content or navigational aids
  • <nav> — navigation links
  • <article> — self-contained content (blog post, news)
  • <section> — thematic grouping of content
  • <aside> — sidebar content
  • <footer> — footer information
  • <main> — primary content of the document

6. What is the difference between semantic and non-semantic tags?

Semantic tags convey meaning about the content they enclose (e.g., <article>, <header>).

Non-semantic tags only define presentation or generic containers without implying meaning (e.g., <div> and <span>).

Using semantic tags is a best practice for modern web development as it enhances accessibility tools, search engine understanding, and future-proofing of code.

7. What are meta tags and why are they used?

Meta tags provide metadata about the HTML document. They are placed inside the <head> section and are not displayed on the page.

Common uses:

  • <meta charset="UTF-8"> — character encoding
  • <meta name="viewport"> — responsive design control
  • <meta name="description"> — page description for search engines
  • <meta name="keywords"> — (less relevant now) keywords
  • Open Graph and Twitter Card meta tags for social sharing

They are essential for SEO, browser behavior, and social media integration.

8. Why do we use the <source> tag inside audio and video tags?

The <source> element is used within <audio> and <video> tags to specify multiple media resources. This allows the browser to choose the most suitable format based on its capabilities and network conditions.

Example:

<video controls>
    <source src="movie.mp4" type="video/mp4">
    <source src="movie.webm" type="video/webm">
    Your browser does not support the video tag.
</video>

9. What is iframe and where is it used in real-time applications?

An iframe (inline frame) is an HTML element that embeds another HTML document within the current page.

Real-time applications:

  • Embedding YouTube or Vimeo videos
  • Third-party payment gateways (e.g., Stripe checkout)
  • Google Maps
  • Advertising banners
  • Live chat widgets
  • Social media feeds (Twitter timelines, Facebook posts)

Security note: Modern browsers restrict iframe capabilities via sandbox attributes and CSP headers.

10. What is the difference between block-level elements and inline elements?

Block-level elements start on a new line and take up the full available width.

Examples: <div>, <p>, <h1>–<h6>, <section>, <article>.

Inline elements flow within the text and only take the width necessary for their content.

Examples: <span>, <a>, <strong>, <em>, <img>.

CSS properties such as display: block; or display: inline; can override default behavior.
