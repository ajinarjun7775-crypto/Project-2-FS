Introduction to CSS

Cascading Style Sheets (CSS) is a stylesheet language used to describe the presentation of a document written in HTML or XML. CSS separates content from presentation, enabling developers to create visually engaging websites efficiently.

Key principles include the cascade, specificity, and inheritance, which determine how styles are applied when multiple rules target the same element.

CSS Selectors

Selectors are patterns used to select the HTML elements you want to style. They range from simple element selectors to complex attribute and pseudo-class selectors.

Common Selectors

  • Element: p { } - Targets all paragraph elements
  • Class: .highlight { } - Targets elements with class "highlight"
  • ID: #header { } - Targets element with id "header"
  • Descendant: ul li { } - Targets li inside ul

The CSS Box Model

Every HTML element is a rectangular box consisting of content, padding, border, and margin areas.

Box Sizing: The box-sizing property determines whether padding and border are included in the element's width and height. Use border-box for predictable layouts.

CSS Flexbox

Flexbox is a one-dimensional layout method for laying out items in rows or columns. It excels at distributing space and aligning items.

Key Flex Properties

  • display: flex; - Creates a flex container
  • justify-content - Aligns items along main axis
  • align-items - Aligns items on cross axis
  • flex-wrap - Controls wrapping behavior

Responsive Design

Responsive web design ensures optimal viewing experience across various devices. Key tools include media queries, relative units (%, em, rem), and modern layout methods like Flexbox and Grid.
