INLINE

Inline is to design a spcific elements using style attribute in the HTML file in the HTML tags or elements.

Key Characteristics: Styles are written directly inside the HTML tag. Highest specificity (priority) among the three methods. Affects only that specific element.

Advantages: Quick for one-off styling or testing. Overrides both internal and external styles. Useful for dynamic styling via JavaScript.

Disadvantages: Poor maintainability (mixes presentation with content). Cannot reuse styles. Leads to bloated HTML code. Not recommended for large-scale projects.
